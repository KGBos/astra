## 📢 Team Announcements
- **🎨 ASCII IDENTITY (2026-08-24)**: Direction from Leon — coloured ASCII means coloured **characters** on the terminal background, not coloured cells. Measured why today's ASCII mode looks weak: glyphs encode **no luminance** (a lit wall and a shadowed wall both print `#####%######%#%` — all depth lives in the colour), and **23% of sky cells are a space glyph with only a background colour**, so with fills off the sky disappears. New tickets **T-33** (per-material luminance→glyph ramp) and **T-34** (sky as glyph density) are unblocked and are the highest-value visual work on the board — they decide what the pixels *mean* before LOD adds more of them. **T-35** then makes `blocks` / `ascii-color` / `ascii-mono` first-class and art-directed. T-18's quadrant blocks are rescoped to `blocks` mode only (they are Unicode, not ASCII).
- **🔌 BACKEND (2026-08-24)**: The renderer already emits a backend-agnostic grid of `(glyph, fg, bg)` cells. **T-36** declares a `Display` interface so the ANSI terminal becomes one backend rather than the only one; **T-37** is a one-shift timeboxed web-canvas spike to find out whether the terminal is our fidelity ceiling. Terminal stays the reference backend and Guardrail #1 is untouched. **T-38** Windows support rides the same abstraction. Audio is **experimental** for v1.0 (**T-39**) — visuals first.
- **🗄️ BRANCH RETIRED (2026-08-24)**: `nora-voss/worktree` evaluated and retired; archived as tag `archive/nora-voss-worktree` (nothing lost). **Salvaged a real bug on master**: the 180 m far tier had an unconditional `break` on the first solid cell, so it could only ever return one layer per column and distant skyline depth never worked — measured 0 → 268 columns with stacked silhouettes, perf-neutral, locked by `tests/test_far_tier_layering.py`. Her perspective overhaul was **rejected**: master's projection supersedes it and her branch uses the reciprocal `CELL_ASPECT` convention, so merging would silently invert vertical scale. `scale.py` / `vehicle_dims.py` retained as reference data for T-09/T-20 rather than landed as dead code. Full rationale in `team/TASKBOARD.md` → Salvage record.

Full design in `docs/DESIGN_LOD_FIDELITY.md` (mip pyramid, per-column level selection, Bayer cross-fade, world-anchored detail synthesis, near-field decals, sub-cell quadrant blocks).
